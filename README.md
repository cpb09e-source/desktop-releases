# Desktop installers

Windows installers for the tournament organizer desktop app. Nothing else lives
here: the application itself is a small shell around the live site, and its
source is in a private repository.

Each release says which site that build opens, and carries the installer's
SHA-256 so a download can be checked.

The installers are **not code-signed yet**, so Windows shows "Windows protected
your PC" the first time one runs. Press **More info**, then **Run anyway**.

They live here rather than on the product's own site because downloads here cost
nothing, while on the site's hosting plan they would spend the same monthly
credits that keep the site online.
